## Modeling and data

- Use only the provided competition dataset; external datasets, scraped data, and additional labeled data are prohibited unless organizers explicitly allow them.
- Public libraries are allowed. The supplied rules allow pretrained models provided no external training data is used; seek organizer clarification for any uncertain model or training setup.
- The dataset cannot be shared, published, or used outside this competition.
- Work must be original, reproducible, and explainable. Document preprocessing, model architecture, hyperparameters, training, and evaluation.
- Evaluation uses Macro F1 over the three classes. The private leaderboard determines final leaderboard ranking.

## Required deliverables

1. Submit predictions as a CSV on Kaggle before the deadline, matching `sample_submission.csv` (`id,y_pred`).
2. Submit the complete `.ipynb` or `.py` for the best result using the organizers' form. The supplied rules say code can be submitted only once.
3. Select up to two submissions for final private leaderboard evaluation, as permitted by the supplied rules.

Both predictions and source code are mandatory. Check the actual deadline and daily submission allowance on Kaggle; the supplied screenshots do not establish an exact deadline.

## Shortlisting and presentation

The supplied rules describe a top-10 shortlist using private leaderboard performance and technical evaluation. Shortlisted teams must give a presentation of at most five minutes covering the problem, methodology, model rationale, results, challenges, and improvements. Judges select the top five based on performance, presentation, and ability to explain the work.
